# Glossary

Plain meanings for words you will meet.

| Word | Meaning |
|---|---|
| **AUR** | The coin of AUREN. |
| **Spark** | The smallest piece of AUR. 1 AUR = 1,000,000,000 sparks. |
| **Wallet** | The app that holds your keys and lets you send and receive. |
| **Address** | Like a bank account number for receiving AUR. Starts with `aur1`, `taur1` or `daur1`. Safe to share. |
| **Recovery key** | The secret that can rebuild your wallet. Never share it. |
| **Node** | A computer that keeps a copy of the network and checks every payment. |
| **Validator** | A node that also confirms new blocks and is paid for it. |
| **Block** | A batch of payments confirmed together, about every 1 to 2 seconds. |
| **Transaction** | A payment or action. The wallet calls them "payments". |
| **Fee** | A small payment to the network for confirming yours. It is burned. |
| **Burn** | Removing coins from existence for good. |
| **Staking** | Locking AUR behind a validator to earn rewards. |
| **Unbonding** | The waiting period before staked coins come back. |
| **Commission** | The part of staking rewards a validator keeps. |
| **Faucet** | A button that gives you coins on the devnet and testnet. |
| **Devnet / Testnet / Mainnet** | The three networks. Mainnet is the real one. |
| **Explorer** | A website to look up blocks, payments, addresses and names. |
| **Name / domain** | An easy name for an address, like `alice.aur`. |
| **TLD / name ending** | The last part of a name: `.aur`, `.david`. You can create your own. |
| **Trusted helpers** | People or wallets that can help you recover your account (called guardians in the technical docs). |
| **Daily limit** | The most that can leave your account per day. |
| **Proposal / governance** | A suggested change to network settings that stakers vote on. |
| **Epoch** | A period of blocks. Node rewards are paid per epoch. |
| **Node reward** | AUR paid to nodes that prove they store the chain. |
| **EVM** | The system that runs smart contracts, compatible with Ethereum. |
| **Smart contract** | A program that lives on the network. |
| **RPC** | The way apps talk to a node. |
| **SDK** | A code library for building apps that use AUREN. |
