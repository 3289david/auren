Help run the network

Run an AUREN node on your own computer

A node keeps its own copy of the network and checks every block. The more people run one, the harder AUREN is to control. It's free, works on a normal computer, and takes about five minutes.

You join the one AUREN network (testnet, devnet, and later mainnet). You don't create your own. Test coins have no monetary value.

1. Download

Download for Windows (.zip) Download for Mac / Linux / Android (.tar.gz)

Small download (under 200 KB). It contains no private keys and nothing is installed system-wide.

2. Run it

Windows

  1. Unzip the download.
  2. Right-click install\windows\Install-AUREN.ps1 → Run with PowerShell. It installs Node.js if needed and adds AUREN Node to your Start Menu.
  3. Open AUREN Node and choose Testnet.

Mac and Linux

  1. Install Node.js 20 or newer from nodejs.org.
  2. Unpack the download and open a terminal inside it.
  3. Run ./auren join testnet

Android

  1. Install Termux from F-Droid.
  2. Copy the download into Termux and unpack it.
  3. Run sh install/android/termux-setup.sh

This runs a real node through Termux. A standalone Android app isn't available yet.

3. Check it's working

The node window shows new blocks as they arrive. In a second window, run ./auren status (Windows: auren.cmd status). You should see running … in sync. Your node also serves this website and the explorer on your own computer.

Good to know

Is it safe to leave running?

Yes. By default your node only talks to the network and answers you; it doesn't open itself to the internet.

Will it use a lot of space?

On the test network, very little. It only stores the chain's blocks.

Do I earn anything?

Running a regular node helps the network but doesn't earn rewards. Earning comes from staking AUR with a validator in the wallet.

Stopping it

Close the window or press Ctrl+C. Run it again any time and it picks up where it left off.

AUREN is a test network. Test coins have no monetary value.
