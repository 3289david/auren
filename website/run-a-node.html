Help run the network

Run an AUREN node on your own computer

A node keeps its own copy of the network and checks every block. The more people run one, the harder AUREN is to control. It's free, works on a normal computer, and takes about five minutes.

You join the one AUREN network (testnet, devnet, and later mainnet). You don't create your own. Mainnet AUR is the real coin.

1. Download

Node: runs the network

Earns AUR while it runs. One file, no install.

Windows (.exe)Android (.apk)

Wallet: hold and send AUR

Your keys stay on your device. Connects to the network you pick.

Windows (.exe)Android (.apk)

Mac and Linux: download the .tar.gz, or the .zip (needs Node.js 20 or newer). All files are on the releases page. The apps are not signed by a store: Windows may show a SmartScreen warning (More info, then Run anyway) and Android asks you to allow installs from this source.

2. Run it

Windows

  1. Download AUREN-Node.exe and double-click it.
  2. Choose Join the testnet and earn AUR.
  3. Leave the window open. If Windows shows a warning, choose More info, then Run anyway.

Mac and Linux

  1. Install Node.js 20 or newer from nodejs.org.
  2. Unpack the download and open a terminal inside it.
  3. Run ./auren join testnet

Android

  1. Download AUREN Node (.apk) and open it. Allow installs from this source when asked.
  2. Pick a network, keep Earn AUR on, and tap Start node.
  3. Leave it plugged in. Open the wallet or explorer from the same screen.

64-bit phones only (arm64 or x86_64). Prefer Termux? See install/android/termux-setup.sh.

3. Check it's working

The node window shows new blocks as they arrive. In a second window, run ./auren status (Windows: auren.cmd status). You should see running … in sync. Your node also serves this website and the explorer on your own computer.

Good to know

Is it safe to leave running?

Yes. By default your node only talks to the network and answers you; it doesn't open itself to the internet.

Will it use a lot of space?

On the testnet, very little. It only stores the chain's blocks.

Do I earn anything?

Yes. Start your node with --earn and it locks a small deposit, proves each epoch that it really stores the chain, and receives a share of new AUR. You get the deposit back when you stop. Every block a few earning nodes are also drawn at random and paid; hardware and coin balance do not change the odds (how the random draw works).

Stopping it

Close the window or press Ctrl+C. Run it again any time and it picks up where it left off.
