Transaction types

Every action on AUREN is a transaction of one of these types. Generated from the source (src/tx.js).

Cost has two parts, a compute cost and a state cost, each priced by its own fee level. The last column is the fee at the lowest fee level, in AUR. Fees are burned. How to build and sign one: Integrate.
