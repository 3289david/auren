Error codes

What the network says when something does not work. A transaction can be rejected before it is included (it never costs anything), or fail after inclusion (the fee is still charged). The wallet shows these in plain words; this page is for developers. Generated from the source.

CodeMeaning
ALREADY_PROVENThis node already proved storage this epoch
AMOUNT_TOO_SMALLThe amount rounds to nothing
BAD_BODYA field in the transaction body is missing or invalid
BAD_FEEFee fields are invalid
BAD_FROMThe sender address is invalid
BAD_NONCEThe payment number is wrong (use pendingNonce)
BAD_PROOFThe storage proof does not match
BAD_PUBThe public key is invalid
BAD_SCHEMEUnknown signature type
BAD_SIGNATUREThe signature does not match
BAD_TXThe transaction is malformed
BAD_VERSIONUnsupported transaction version
CONSENSUS_KEY_IN_USEThat validator key is already used
DAILY_LIMIT_EXCEEDEDOver the account's daily limit
EXCEEDS_STAKEYou asked to unstake more than you have
FEE_TOO_LOWmaxFee is below the current fee
INSUFFICIENT_BALANCENot enough balance
INSUFFICIENT_BONDNot enough to lock the node bond
INSUFFICIENT_DEPOSITThe proposal deposit is too small
INSUFFICIENT_FEE_FUNDSNot enough balance to pay the fee
INTRINSIC_GAS_TOO_LOWGas limit below the minimum for a contract call
MEMPOOL_FULLThe node is too busy; try again or another node
NAME_DOES_NOT_RESOLVE_TO_YOUYou can only make a primary name that points to you
NAME_NOT_FOUNDNo such name

NO_SUCH_PROPOSALNo such proposal

REPLACEMENT_UNDERPRICEDTo replace a waiting payment, pay a higher tip

STILL_JAILEDThe pause period has not ended
TLD_NOT_FOUNDThat name ending does not exist
