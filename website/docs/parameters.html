Network parameters

Every setting of the network, with its default. A network's genesis file may override any of them; some can be changed later by a governance vote (see Governance). This page is generated from the source (src/params.js), so it always matches the code.

Amounts shown in AUR are stored as sparks (1 AUR = 1,000,000,000 sparks). Fees are in sparks per resource unit.
